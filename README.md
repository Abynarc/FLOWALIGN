# FLOWALIGN

Выравнивание вокального дубля по эталону с сохранением высоты голоса. AU для macOS и VST3 для Windows.

Интерфейс **Русский / English**: переключатель **RU / EN** справа от «Обход». Язык сохраняется в проекте.

![FLOWALIGN](docs/images/flowalign.png)

- Импорт аудиофайлов и регионов, захват через Side Chain.
- Точность, естественность и предел растяжения; до восьми пар фраз.
- Прослушивание эталона, дубля и результата, сравнение «До / После».
- Экспорт WAV и карты тайминга CSV, перенос WAV в секвенсор.
