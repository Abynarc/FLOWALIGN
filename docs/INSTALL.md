# Установка FLOWALIGN 0.3.2

Скачайте **FLOWALIGN-0.3.2-Universal.pkg** из [релиза v0.3.2](https://github.com/Abynarc/FLOWALIGN/releases/tag/v0.3.2). Самостоятельный PKG содержит плагин; DMG, Python и Терминал для установки не нужны.

1. Сохраните проект Logic и закройте Logic Pro. Захваченное аудио сохраняется в состоянии проекта.
2. Откройте PKG двойным щелчком, нажмите «Продолжить» и введите пароль администратора.
3. Откройте Logic заново: **Audio FX → Audio Units → FLOWMINNERS → FLOWALIGN**.
4. В меню шестерёнки плагина проверьте версию 0.3.2.

Сборка содержит arm64 и x86_64, минимальная macOS — 12.0. Исполнение проверено на Apple Silicon с текущей macOS; Intel и macOS 12 являются целями сборки, но отдельно не проверялись. Требования версии Logic могут быть выше.

## Если macOS блокирует открытие

AU подписан ad hoc; PKG без Developer ID и нотариального заверения Apple. После попытки открыть скачанный установщик перейдите в **Системные настройки → Конфиденциальность и безопасность** и выберите **«Всё равно открыть»** для этого файла. [Инструкция Apple](https://support.apple.com/102445). Отключать Gatekeeper целиком не нужно. Если на управляемом студийном компьютере исключение недоступно, обратитесь к администратору студии.

## Папки и резервные копии

Плагин: `/Library/Audio/Plug-Ins/Components/FLOWALIGN.component`.

Резервные копии: `/Library/Application Support/FLOWMINNERS/FLOWALIGN/Backups`.

Системная копия резервируется перед заменой. После проверки нового AU прежняя пользовательская копия текущего вошедшего пользователя переносится из `~/Library/Audio/Plug-Ins/Components` в резервные копии, чтобы не перекрывать системную. Копии других пользователей не изменяются; при установке без вошедшего пользователя их состояние нужно проверить отдельно.

Установщик проверяет подпись и SHA-256 всех файлов AU. Символическая ссылка или необычный файл вместо ожидаемого компонента не заменяются автоматически.

## Если плагин не появился

Закройте и снова откройте Logic. При необходимости перезапустите Mac, откройте менеджер плагинов Logic и повторите проверку FLOWALIGN. Убедитесь, что установщик завершился успешно, а macOS подходит.

Дополнительная диагностика из Терминала:

```bash
auval -v aufx Flal Flmn
```

Эта команда не заменяет прослушивание проекта.

## Проверка скачивания

Скачайте файлы релиза и `SHA256SUMS.txt` в одну папку, затем при необходимости выполните:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Контрольные суммы подтверждают целостность; подпись Developer ID они не заменяют.

## Перенос проекта

Сохраните проект, чтобы захваты и результаты попали в состояние плагина. Подготовленные для перетаскивания WAV находятся в `~/Library/FLOWMINNERS/FLOWALIGN/Results`. Если Logic использует такой файл, скопируйте аудио внутрь проекта средствами Logic перед переносом проекта на другой компьютер. Не удаляйте используемый WAV.
