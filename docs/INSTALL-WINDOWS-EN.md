# FLOWALIGN for Windows

Close your DAW and run `FLOWALIGN-0.5.0-Windows-x64-Setup.exe`. The installer supports English and Russian. Rescan plug-ins in your DAW. In FL Studio, open Manage plugins → Find installed plugins. The VST3 is installed to `C:\Program Files\Common Files\VST3\FLOWALIGN.vst3`.

Select **EN** in the language dropdown beside Bypass. Select **RU** to return to Russian. The choice is saved with the project and does not change audio settings. Existing projects open in Russian.

Route the Guide to the sidechain and insert FLOWALIGN on the Dub track. In FL Studio, connect the additional input in wrapper → Processing. Capture Guide + Dub, press Play, then Stop. You can also import audio files. Click Align and compare Before / After. Drag the rendered output onto the timeline, or click Open WAV to reveal it in File Explorer.

The installer backs up the previous version under `C:\ProgramData\FLOWMINNERS\FLOWALIGN\Backups`. Uninstall using Windows Apps settings. Backups are retained. Windows 10/11 x64 is required. The installer has no publisher certificate.
