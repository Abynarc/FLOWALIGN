# FLOWALIGN для Windows

1. Скачайте `FLOWALIGN-0.5.0-Windows-x64-Setup.exe` из [релиза](https://github.com/Abynarc/FLOWALIGN/releases/tag/v0.5.0).
2. Сохраните проекты и закройте секвенсор.
3. Запустите EXE и выполните установку.
4. В FL Studio: **Manage plugins → Find installed plugins**. Добавьте FLOWALIGN как эффект на канал микшера.

Windows 10/11 x64, секвенсор с поддержкой VST3. Папка плагина: `C:\Program Files\Common Files\VST3\FLOWALIGN.vst3`.

Выберите **RU** или **EN** справа от «Обход». Язык сохраняется в проекте.

Направьте эталон в Side Chain, вставьте плагин на дубль. В FL Studio подключите дополнительный вход в wrapper → Processing. Выберите захват обоих сигналов, нажмите «Запись», затем Play и Stop в секвенсоре.

Можно загрузить файлы через меню или перенести их на две входные волны. Для переноса регионов подготовьте фрагменты одинаковой длины. Нажмите «Выровнять», сравните «До / После» и перенесите готовый WAV на таймлайн. Кнопка «Открыть WAV» показывает файл в Проводнике.

Моно/стерео, до 120 секунд на сигнал. До восьми пар; аудио и результаты сохраняются в проекте.

При обновлении предыдущая версия сохраняется в `C:\ProgramData\FLOWMINNERS\FLOWALIGN\Backups`. Удаление через «Установленные приложения» сохраняет резервные копии и пользовательское аудио. Установщик без сертификата издателя.
