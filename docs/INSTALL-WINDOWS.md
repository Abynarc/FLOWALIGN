FLOWALIGN 0.4.1 · FLOWMINNERS · Windows VST3

УСТАНОВКА
1. Сохраните проекты и закройте секвенсоры.
2. Запустите FLOWALIGN-0.4.1-Windows-x64-Setup.exe и разрешите установку.
3. В FL Studio: Options → Manage plugins → Find installed plugins.
   Выберите FLOWALIGN как эффект на канале микшера с дублем.
   В других VST3-секвенсорах обновите список плагинов.

Требования: Windows 10/11 x64, 64-разрядный VST3-секвенсор.
Стандартная папка: C:\Program Files\Common Files\VST3\FLOWALIGN.vst3
Работа в FL Studio, REAPER, Cubase, Studio One и Ableton Live зависит от поддержки
VST3 и маршрутизации дополнительных входов выбранной версией программы.
Logic Pro для Windows отсутствует. AU на Windows не используется.
Установщик не подписан сертификатом издателя Windows.

БЫСТРЫЙ СЦЕНАРИЙ БЕЗ ЗАПИСИ
1. Подготовьте два аудиофрагмента одинаковой длины.
2. Перенесите по одному на волны «Опорная дорожка» и «Доп. дорожка».
   При переносе в области волн проверяется одинаковая длительность.
   Поддерживаются настоящие файлы OLE/CF_HDROP. Из Проводника также можно.
   В FL Studio используйте ручку Drag/copy sample/selection редактора Edison;
   выделите нужный фрагмент. Edison переносит выделение, иначе весь сэмпл.
   Перенос внутреннего клипа Playlist работает только если FL передаёт файл:
   внутренний объект проекта сам по себе не содержит доступного плагину аудио.
   Общая поддержка виртуальных FILECONTENTS здесь не реализована.
   Если хост не отдаёт файл, используйте штатный захват сигналов через Side Chain.
   Не запускайте секвенсор от администратора: Windows ограничивает перенос файлов
   между программами с разными уровнями прав.
3. Проверьте эталон и дубль отдельными кнопками «Слушать».
4. Нажмите «Выровнять», дождитесь третьей волны, сравните «До / После».
5. Зажмите кнопку переноса результата и перетащите её в Playlist/таймлайн.
   WAV готовится автоматически. Если хост не принимает перенос, откройте готовый
   WAV кнопкой у результата и перенесите из Проводника. Обычный клик не создаёт трек.

ЗАХВАТ С ТАЙМЛАЙНА
Плагин ставится на дубль. Эталон направляется в дополнительный вход Side Chain.
В FL Studio направьте эталон на канал дубля командой Sidechain to this track;
в настройках wrapper → Processing подключите дополнительный вход FLOWALIGN
к этому sidechain. Mute/Solo не заменяют маршрутизацию входа.
Выберите «Оба сигнала», поставьте курсор, нажмите «Запись» и Play секвенсора.
После Stop нажмите «Выровнять». Можно записать эталон и дубль отдельно.
Микрофон и запись на диск для захвата не требуются.

ПЛЕЕР И ТРАНСПОРТ
Кнопки «Слушать» используют системный выход Windows в WASAPI shared mode,
включая пересчёт частоты для прослушивания. Настройки ASIO и частота проекта
не изменяются. Остановите транспорт для изолированного прослушивания.
Если ASIO/другая программа заняла устройство эксклюзивно, отдельный плеер может
не открыть системный выход: освободите устройство либо используйте режим транспорта.
Для загруженных файлов позиция таймлайна не передаётся. Поставьте курсор хоста
на начало дубля, нажмите кнопку связи и выберите режим транспорта.

СОХРАНЕНИЕ И УДАЛЕНИЕ
Сигналы, результат, пары и параметры сохраняются внутри состояния плагина проекта.
WAV для переноса: %APPDATA%\FLOWMINNERS\FLOWALIGN\Results.
Перед переносом проекта на другой компьютер соберите использованное аудио
внутрь проекта средствами секвенсора.
При обновлении старая системная копия проверяется и резервируется в
C:\ProgramData\FLOWMINNERS\FLOWALIGN\Backups.
Удаление через «Установленные приложения → FLOWALIGN VST3» удаляет плагин;
готовые WAV, проекты и резервные копии сохраняются.

ОГРАНИЧЕНИЯ
Моно/стерео, 8–192 кГц, до 120 секунд на сигнал, суммарно 256 МиБ, до 8 пар.
Нет ARA, чтения всех тейков проекта, автоматического Play и создания трека кнопкой.
Поддержка конкретной версии секвенсора требует проверки в этой программе.
Сборка и автоматические проверки VST3 выполняются на Windows x64; ручное
прослушивание и работа непосредственно в FL Studio на этой машине не проверены.
